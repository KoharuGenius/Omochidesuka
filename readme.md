# お客様、当店のカードはおもちですか？
---
# 概要
- ティラノスクリプトで作成するショートショートノベルゲーム
- プレイ時間は数分

# ストーリー
- 舞台は主人公が昼休みに行きつけている個人商店。ある日、新人の「望美ちゃん」がレジに立っていて…
- 「お客様、当店のカードはおもちですか？」から始まるハートフル(?)コメディ
- 四種類のエンディング
    - ①normal：普通にお店のカードを出してお買い物。ちょっとせつない
    - ②Bad：主人公がお餅として焼かれて、店頭に並べられてしまう。ちょっとホラー
    - ③熱血：意気投合する二人。お餅を使ったカードゲームを開発してしまう。ラスト「お客様、今日もデュエルしましょう」
    - ④ロマンス：数分で始まる恋。ラストに月収３ヶ月分の切り餅をプレゼントして主人公がプロポーズ
- ストーリー内の質問および選択肢はすべてのルートで共通
    - 質問はストーリー全体で5個
    - うち2個はルート分岐に関係なく、「望美ちゃん」の反応を見るだけ
    - ３問目からルート分岐発生。ここでBadや熱血エンドで終了（脱落）する可能性あり
    - ５問目は normalエンドかロマンスエンド

# 準備するアセット
- 背景：店内レジ（AI生成OK）
- 望美ちゃんの立ち絵＋表情差分（作者が描く）
- ロマンスエンド用の「月収３ヶ月分の切り餅」（AI生成OK）
- SE,BGM：フリー素材
